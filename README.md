# ProjectUnity

Rebuild of [projectunitynfp.org](https://projectunitynfp.org) — a static site (HTML/CSS/JS) prepared for migration into a custom WordPress theme on SiteGround.

## Pages

- `index.html` — Home with interactive US presence map
- `about.html` — About + Leadership + Board + Advisory (tabbed)
- `catalyst-academy.html` — Program overview + Mentors + Speakers + Become a Mentor + Apply
- `catalyst-academy-2023.html` / `-2024.html` / `-2025.html` — Cohort pages
- `yphic.html` — Y-PHIC program
- `research.html` — Research & Press
- `support.html` — Donate / Zeffy embed
- `contact.html`
- `privacy-policy.html`

## Local preview

Open any `.html` directly in a browser, or run a static server:

```bash
python3 -m http.server 8000
```
